# TurkuazVM Guvenlik Politikasi

## Desteklenen Surumler

Aktif `main` dali ve son yayinlanan patch release guvenlik duzeltmeleri icin onceliklidir. Eski release serileri yalniz kritik bir geriye donuk uyumluluk ihtiyaci varsa ele alinir.

## Guvenlik Acigi Bildirimi

Guvenlik acigi, kimlik bilgisi sizintisi, yetki atlama, host izolasyonu sorunu veya uzaktan kod calistirma riski iceren bulgular icin public issue acmayin.

Repository uzerinde GitHub private vulnerability reporting aciksa `Security` alanindaki private bildirim akisini kullanin. Bu secenek yoksa repo sahibiyle ozel kanal uzerinden iletisime gecin.

Bildirimde mumkunse etkilenen surum, tekrar adimlari, beklenen/gercek davranis, log ve risk etkisini ekleyin. Secret, token, parola veya gercek kullanici verisini public alanda paylasmayin.
