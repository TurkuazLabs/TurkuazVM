# TurkuazVM v0.41.2

## Kapsam

- Connection Center SSH/RDP Hazirla butonlari running VM icin aktif kalir.
- Kullanici running VM yeniden yapilandirilacaksa acik onay verir.
- Desktop Service VM'yi durdurur, host port yayinini ekler ve VM'yi yeniden baslatir.
- Publish basarisiz olursa VM'yi onceki running durumuna geri getirmek icin recovery restart dener.
- Hazirlama sonrasi dashboard ve network state yenilenir.
- SSH/RDP guest servis kurulumu otomatik yapilmaz; bu patch host erisim yolunu hazirlar.
