# TurkuazVM v0.41.5

## Kararlar

- Windows installed paket writable state'i kurulum dizininde tutmaz; `%LOCALAPPDATA%\TurkuazVM` kullanir.
- Portable paket `README-PORTABLE.txt` marker'i ile klasor-ici runtime davranisini korur.
- Installed runtime config kullanici alanina materialize edilir; install asset yollarinin Engine/Display/helper/script bolumu mutlak kurulum yollarina donusturulur.
- Kullanici tarafindan degistirilebilen `download-sources.yml` yalniz ilk materialization'da seed edilir.
- NSIS `installMode: both` kullanir; tek installer current-user ve per-machine kurulum sunar.
- Uninstall kullanici runtime/config verisini silmez.
- Turkce MultiUser sayfasi Tauri `installerHooks` uzerinden lokalize edilir; upstream installer template'i fork edilmez.

## Fail-closed dogrulama

- Static v0.41.5 contract AppData, portable marker, dual install-mode ve Turkce hook baglantisini kilitler.
- Windows Distribution gercek release binaryleri ve NSIS installer uretir.
- Smoke testi `/CurrentUser` ve `/AllUsers` kurulumlarini ayri registry scope'larinda gercekten kurar.
- Her modda Desktop baslatilip runtime config materialization'i kontrol edilir.
- Her mod sessiz uninstall edilir ve user runtime config'in korundugu dogrulanir.
- Compiler Log Gate Windows/Linux ve diger runtime/policy gate'leri release head'i icin PASS olmadan merge yapilmaz.

## Sonraki olasi adimlar

- Installer icin code-signing sertifikasi ve imza zinciri.
- QEMU dependency bootstrap UX'inin installer/setup deneyimine daha gorunur baglanmasi.
- MSI paketi ancak kurumsal deployment ihtiyaci netlesirse eklenir.
