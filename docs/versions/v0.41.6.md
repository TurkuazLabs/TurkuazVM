# v0.41.6 - TurkuazLabs Windows Install Root

## Karar

TurkuazVM'in Windows kurulu uygulama dosyalari marka ailesi altinda toplanir:

- All Users: `C:\Program Files\TurkuazLabs\TurkuazVM`
- Current User: `%LOCALAPPDATA%\TurkuazLabs\TurkuazVM`

Bu karar, ileride ayni makinede baska TurkuazLabs uygulamalarinin da ortak bir ust klasor altinda duzenli tutulabilmesini saglar.

## Runtime verisi neden tasinmadi?

Kurulum kokuyla writable runtime/config kokunun gorevi farklidir. v0.41.5 ile kullanici verisi `%LOCALAPPDATA%\TurkuazVM` altinda kurulum dosyalarindan ayrilmisti. v0.41.6 bu davranisi korur; boylece kurulum yolu duzeltmesi veri migrasyonuna donusmez ve mevcut kullanici ayarlari risk altina girmez.

## Teknik uygulama

Tauri 2.x NSIS konfigurasyonu dogrudan markali bir default install-directory alanina sahip olmadigi icin, Windows packaging sirasinda resmi Tauri CLI 2.11.4 NSIS template'i kullanilir. Template exact Git blob SHA ile dogrulanir ve yalniz install-root literal'leri fail-closed olarak patch edilir. Patchlenen template gecicidir ve build sonunda silinir.

## Dogrulama hedefi

Windows CI yalniz installer'in build olmasini degil, gercek kurulum sonucunu da kontrol eder. `/CurrentUser` ve `/AllUsers` modlarinda registry scope, tam install path, Desktop/Engine/Display dosyalari, AppData runtime materialization ve silent uninstall birlikte test edilir.
