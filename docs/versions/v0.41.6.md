# v0.41.6 - TurkuazLabs Windows Install Root

## Karar

TurkuazVM'in Windows kurulu uygulama dosyalari marka ailesi altinda toplanir:

- All Users: `C:\Program Files\TurkuazLabs\TurkuazVM`
- Current User: `%LOCALAPPDATA%\TurkuazLabs\TurkuazVM`

Bu karar, ileride ayni makinede baska TurkuazLabs uygulamalarinin da ortak bir ust klasor altinda duzenli tutulabilmesini saglar.

## Runtime ve buyuk kullanici verisi ayrimi

Kurulum kokuyla writable runtime/config ve buyuk VM medyalarinin gorevi farklidir. v0.41.6 bu alanlari uc katmana ayirir:

- Uygulama binary/resource: `Program Files/TurkuazLabs/TurkuazVM` veya current-user `LocalAppData/Programs/TurkuazLabs/TurkuazVM`.
- Config/runtime: `%LOCALAPPDATA%\TurkuazVM`.
- Buyuk kullanici verisi: `%USERPROFILE%\TurkuazVM`.

Buyuk veri kokunde varsayilan klasorler `VMs`, `ISOs` ve `Images\Android` olur. Boylece qcow2/raw diskler, installer ISO'lari ve Android virtual/system image ciktilari AppData icinde gizli ve daginik kalmaz. `TURKUAZVM_USER_DATA_ROOT` yalniz ileri seviye override/test ihtiyaci icindir; normal kullanici icin gerekli degildir.

## Teknik uygulama

Tauri 2.x NSIS konfigurasyonu dogrudan markali bir default install-directory alanina sahip olmadigi icin, Windows packaging sirasinda resmi Tauri CLI 2.11.4 NSIS template'i kullanilir. Template exact Git blob SHA ile dogrulanir ve yalniz install-root literal'leri fail-closed olarak patch edilir. Patchlenen template gecicidir ve build sonunda silinir.

## Dogrulama hedefi

Windows CI yalniz installer'in build olmasini degil, gercek kurulum sonucunu da kontrol eder. `/CurrentUser` ve `/AllUsers` modlarinda registry scope, tam install path, Desktop/Engine/Display dosyalari, AppData runtime materialization, USERPROFILE tabanli `VMs/ISOs/Images/Android` kokleri ve silent uninstall birlikte test edilir.
